C# - Ovning 8: Extra uppgift

Den har delen visar hur en klass kan implementera tva interface som bada har
metoden Run(), men med olika returtyper.

Explicit interface implementation behovs eftersom C# inte tillater tva vanliga
metoder med samma namn och parametrar som bara skiljer sig at genom returtypen.

Skapa ett Console App-projekt i Visual Studio och ersatt innehallet i Program.cs
med koden i Program.cs.

Forvantad utskrift:
Void Run-metoden körs
Int Run-metoden körs
